SPEC

Design spec — what was extracted, what was assumed

Scope & roles
Product: the €79 paste-a-link apartment risk report. The SaaS platform (boards J1–P1 in this project) is explicitly out of scope.
One role, two registers: Mikko (guided, first-time) and Anne (power buyer, 20-pack). No permissions model — the same surfaces serve both via progressive disclosure.
Platforms: responsive web (1440 / 390), transactional email (600), print A4, Open Graph card.
Languages: FI primary, EN parity. Finnish passes rendered on the verdict card, report header and one email.
Canonical deal — used on every frame
Tuomiokirkonkatu 23 B 14, Tampere · 2h+kk, 54 m², 4/6 krs · As Oy Tampereen Tuomiokolmio, 1962 · leasehold plot.
Asking 104 600 € + loan share 13 400 € = debt-free 118 000 € (2 185 €/m², 16 % under district median).
Rent P10 780 / P50 845 / P90 910 €. Gross yield 8.6 % → real yield 5.8 % after a modelled 58 200 € pipe-renovation liability.
3 flags (1 high, 2 caution) · company grade C · municipality A · fails Balanced policy 3 / 14.
Assumptions to correct if wrong
“First report free” is read as: the free summary is free for every listing, and a new account’s first full unlock is free — the purchase screen carries that claim honestly (R6-1).
Verdict semantics: green / amber / red are reserved for pass / caution / fail only. Interaction is Steel Blue; Neon Lime appears once per screen, on the primary action.
Document register: white sheet on Off White paper, no app sidebar, no dashboard chrome. Type is Space Grotesk (headings, verdict figures) + Satoshi (body), tabular figures throughout.

Handoff notes — R1
Routes → / · /analysing/:id · /r/:slug (slug = address, public–private controlled by owner, see R8)
Data → Analysis {id, slug, status: queued|running|done|refused|withdrawn|failed, steps[{key,label,foundFact,flagged,t}], listing{addr,type,m2,floor,built,askPrice,loanShare,debtFree,maintFee,financeFee,oikotieId,fetchedAt}, verdict{grossYield,realYield,liability{total,window,items[{label,amount,basis}]}, grades{company,municipality}, flags[{id,severity,title?,body?,quotes[]?,locked,costRange}]}}
Locked flags → server-side redaction; payload for a locked flag carries only {severity, costRange, locked:true}. The paywall is honest because the data is.
Numbers → engine v2.3 only; UI never computes. fi-FI formatting both languages for € (104 600 €); % uses locale decimals (8.6 % / 8,6 %). All numerals font-variant-numeric:tabular-nums.
State machine → paste → validating → running (SSE, resumable on refresh) → done | refused | withdrawn | failed(retryable). Refresh during running re-attaches to the stream; deep-link to /r/:slug while running shows R1-4.
A11y → progress aria-live polite · verdict h1 receives focus on arrival · chips carry title tooltips · locked rows aria-label “Locked flag, caution severity, cost range …” · all interactive ≥44 px on touch.
Deferred frames — all rendered above: submitting R1-12 · fetch-fail mobile R1-13 · EN⇄FI swap R1-14 · returning-user seam R1-15.
Breakpoints → ≥1280 centered 720/840 column (R1-1/6) · 768–1279 full-width 704 content, inline unlock (R1-16) · ≤767 stacked with sticky unlock bar (R1-3/7).
